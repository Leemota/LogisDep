## 操作指南
常规模式：
- WASD：平移画面。
- 中键单击：重置画面。
- 中键移动：平移画面。
- 滚轮：俯仰画面。
- 左键：选择干员或建筑。
- 右键：打开菜单。
- 左键双击：打开详情。
- B：切换建设模式。
- T：切换科技路线面板。
- Tab：随机选择一个干员。
- F2：全选干员。

选中干员时：
- 左键单击：触摸。
- 右键单击：移动或攻击。
- Tab：编队内切换选择。
- 1-4：触发技能。
- Q：触发天赋。
- T：使用货物。
- 左键货物格：全部丢弃。
- 右键货物格：使用货物。
- LCtrl+左键货物格：丢弃一半货物。
- 在货物格上滚动：切换持有货物。

建设模式：
- X：拆除建筑。
- R：旋转建筑。
- 中键：复制建筑。
- 右键长按：取消建筑蓝图。
